# Dont Fear The Death

[English](#english) | [Deutsch](#deutsch)

## <a id="english"></a>English

### About
"Dont Fear The Death" is a text-based narrative game written entirely in C# (.NET 10). It focuses on atmospheric storytelling through text, visuals, and sound within a console environment.
The purpose of the game is to watch, read, and immerse yourself in the story.

### Features
- **Atmospheric Console Experience**: Custom text rendering and centering.
- **Audio System**: Background music and sound effects integration.
- **Video Settings**: Automated fullscreen mode (simulated F11).
- **Menu System**: Interactive text-based menus for navigation.

### How to Run
#### Method 1: Quick Run
Navigate to `.\Dont_Fear_The_Death\bin\Debug\net10.0\` and run `Dont_Fear_The_Death.exe`.

#### Method 2: Build Release
You can build a clean release version using the included PowerShell script:
```powershell
.\build_release.ps1
```
The executable will be created in `Build\Release\`.

### Controls
- **Number Keys (1-5)**: Navigate through menu options.
- **F11**: Toggle Fullscreen.

### Über das Projekt
"Dont Fear The Death" ist ein textbasiertes Erzählspiel, das vollständig in C# (.NET 10) entwickelt wurde. Der Fokus liegt auf atmosphärischem Storytelling durch Text, Visuals und Sound in einer Konsolenumgebung.
Das Ziel des Spiels ist es, zu beobachten, zu lesen und in die Geschichte einzutauchen.

- **Atmosphärisches Erlebnis**: Benutzerdefinierte Textdarstellung.

- **Video-Einstellungen**: Automatischer Vollbildmodus (F11-Simulation).
- **Menüsystem**: Interaktive textbasierte Menüs zur Navigation.

### Starten des Spiels
#### Methode 1: Schnellstart
Gehe zu `.\Dont_Fear_The_Death\bin\Debug\net10.0\` und starte `Dont_Fear_The_Death.exe`.

#### Methode 2: Release bauen

```powershell
.\build_release.ps1
```
Die ausführbare Datei findest du anschließend unter `Build\Release\`.

### Steuerung
- **Zifferntasten (1-5)**: Navigieren durch die Menüoptionen.
- **F11**: Vollbildmodus umschalten.
